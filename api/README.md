# PHP-приём заявок с сайта

Файл `send-order.php` принимает форму сайта и отправляет текст заявки и вложение в Telegram через Bot API.

## Настройка на cPanel

1. Создайте отдельного бота через `@BotFather`.
2. Добавьте бота в чат менеджеров и получите ID этого чата.
3. Скопируйте `config.local.example.php` в `config.local.php` и заполните:

```php
<?php

return [
    'telegram_bot_token' => 'токен_бота_приема_заявок',
    'telegram_chat_id' => 'id_чата_менеджеров',
];
```

4. Загрузите папку `api` в корень сайта рядом с HTML-файлами.
5. Убедитесь, что на хостинге включены PHP cURL и загрузка файлов. Максимальный размер вложения в обработчике — 20 МБ.

Токен не нужно вставлять в JavaScript или HTML. Файл `config.local.php` закрыт от прямого доступа через `api/.htaccess`.
