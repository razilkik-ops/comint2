# SEO-миграция COMINT

Дата фиксации старого сайта: 2026-07-27.

## Что сохранено

- 115 из 115 старых услуг сопоставлены с новым каталогом.
- Каждая услуга отдается с кодом 200 на прежнем URL.
- Сохранены старые `title`, `description`, canonical, robots, Open Graph, H1, H2/H3 и видимый текст.
- Технические адреса `/services/...` перенаправляются кодом 301 на старые URL.
- Восстановлены 102 статьи и 13 индексируемых категорий на прежних URL.
- Сохранены 734 связанных изображения и документа общим объемом около 118 МБ.
- Новый `sitemap.xml` содержит 240 канонических URL без технических дублей.
- `robots.txt` открывает публичные страницы и закрывает служебные каталоги.

## Услуги без аналога

Таких услуг нет. Контрольный файл `unmatched-legacy-services.csv` содержит только заголовок.

## Требуют решения заказчика

Старый WooCommerce содержал четыре функциональных URL без самостоятельного содержимого:

- `https://comint.by/cart/`
- `https://comint.by/checkout/`
- `https://comint.by/my-account/`
- `https://comint.by/shop/`

Они не включены в новый sitemap и не подменены другой услугой. До запуска нужно решить, остается ли интернет-магазин. Если магазин не нужен, для корзины, оформления заказа и личного кабинета рекомендуется код 410; для `/shop/` нужно отдельно выбрать релевантный каталог или также код 410.

## Контрольные файлы

- `migration-map.json` — подтвержденная карта старых и новых услуг.
- `legacy-products.json` — архив SEO и текстов услуг.
- `legacy-posts.json` — архив статей.
- `legacy-pages.json` — архив постоянных страниц.
- `legacy-categories.json` — архив категорий.
- `legacy-sitemap-inventory.json` — полный реестр старых XML-карт.
- `legacy-media-report.json` — отчет по сохраненным файлам.
- `functional-pages-requiring-decision.csv` — функциональные URL для согласования.
